# Ad Content Generator

## Project Overview

The Ad Content Generator is an AI-powered content generation project designed to create engaging and creative advertising content for products and businesses. It helps users generate UGC (User-Generated Content) advertisement scripts, attention-grabbing marketing hooks, and effective calls to action (CTAs) for social media marketing.

The project uses structured prompts to generate content tailored to specific products, target audiences, and marketing objectives.

## Features

1. UGC Ad Script Generation
   - Generates engaging advertisement scripts for products.
   - Creates conversational and relatable promotional content.
   - Structures scripts with hooks, problems, solutions, product benefits, and CTAs.
   - Supports short-form video advertisements for platforms such as Instagram Reels and YouTube Shorts.

2. Ad Hook Generation
   - Generates attention-grabbing opening lines for advertisements.
   - Helps capture audience attention within the first few seconds.
   - Customizes hooks according to the product and target audience.
   - Supports short-form video marketing.

3. Call-to-Action (CTA) Generation
   - Creates persuasive calls to action for products and businesses.
   - Generates soft CTAs, social engagement CTAs, and direct CTAs.
   - Encourages viewers to take actions such as visiting a store, exploring a product, or making a purchase.

4. Audience-Focused Content
   - Tailors advertising content to specific target audiences.
   - Supports different marketing tones and styles.
   - Helps create relevant and engaging promotional messages.

## Project Structure

The project contains prompt templates and generated advertising content organized into separate directories.

prompts/
    UGC_script.txt
    cta_prompt.txt
    hooks.txt

output/
    UGC_script_output.txt
    cta_prompt_output.txt
    hooks_output.txt

## Technologies Used

- Generative AI and large language models
- Prompt engineering
- Plain text files for storing prompts and generated content
- UGC marketing and digital advertising concepts

## How to Use

1. Open the project directory.
2. Navigate to the prompts directory.
3. Select the appropriate prompt for generating an advertisement script, marketing hook, or CTA.
4. Provide the prompt to a compatible AI language model.
5. Review and refine the generated advertising content.
6. Save the generated output in the output directory.
